**Konductor** is a Nix flake providing hermetic, multi-target polyglot development environments. It delivers consistent tooling across devshells, OCI containers, QCOW2 VMs, and NixOS/Darwin/Home-Manager modules using the **Single Source of Truth (SSOT)** pattern.

<Note type="info" title="Why Konductor?">
  Konductor targets **senior developers and platform engineers** who value reproducibility over convenience and architecture over ad-hoc scripting. It is designed for those who want to treat their development environment as code.
</Note>

## The Problem & Solution

<CardGrid>
  <Card title="The Core Problem" icon="🌪️">
    Modern software development often suffers from configuration drift between local environments, CI pipelines, and production deployments. "Works on my machine" is a symptom of relying on mutable system state (`brew install`, global `pip`, `npm -g`).
  </Card>
  <Card title="The Konductor Solution" icon="🛡️">
    Konductor inverts this model by enforcing **hermetic configuration management**. Tools and their configurations are injected at runtime via Nix wrapper scripts, ensuring consistent behavior across all environments without relying on user home directories or project dotfiles.
  </Card>
</CardGrid>
