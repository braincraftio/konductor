Konductor provides 9 hermetic development shells. Enter any shell with one command — everything you need is on your `PATH`. Click any card below to copy its command.

## Shell Hierarchy

Shells build on each other using Nix `overrideAttrs`. Each layer adds packages and environment variables on top of its parent.

<div className="my-6 overflow-x-auto rounded-xl border border-border-default bg-surface-paper">
  <pre className="p-5 font-mono text-sm leading-relaxed text-text-secondary m-0 bg-transparent border-none">{`default
  ├── python               Python 3.13 + uv, ruff, mypy, bandit
  ├── go                   Go 1.25 + gopls, delve, golangci-lint
  ├── node                 Node.js 22 + pnpm, biome, prettier
  ├── rust                 Rust 1.92.0 + cargo, clippy, rust-analyzer
  ├── dev                  neovim, tmux, forgejo-cli
  └── full                 all languages + IDE + containers
       └── konductor       +qemu, libvirt, OVMF        (x86_64-linux)
            └── frontend   +Playwright, Tauri 2.x      (x86_64-linux)`}</pre>
</div>

Language shells (`python`, `go`, `node`, `rust`) and `dev` each extend `default` independently. `full` combines everything. `konductor` → `frontend` is an accumulative chain — each adds to the previous.

## Environment Variables

Each shell sets environment variables via Nix's `env` attribute — they cannot be overridden by dotfiles.

<div className="overflow-x-auto [&_table]:min-w-[600px]">

| Shell | Variable | Value | Purpose |
|-------|----------|-------|---------|
| python | `UV_SYSTEM_PYTHON` | `1` | Use Nix Python, not uv-managed |
| python | `PYTHONDONTWRITEBYTECODE` | `1` | No `.pyc` files |
| go | `GO111MODULE` | `on` | Modern module mode |
| go | `CGO_ENABLED` | `1` | C interop for cgo |
| node | `NODE_ENV` | `development` | Dev mode |
| rust | `RUST_BACKTRACE` | `1` | Stack traces on panic |
| konductor | `DOCKER_BUILDKIT` | `1` | BuildKit enabled |
| konductor | `DOCKER_HOST` | `unix:///var/run/docker.sock` | Default socket |

</div>
